Edit a Ghost Song `SaveData` file (Steam Deck or PC) to change nanogel, health, base stats and any other saved value. A quick-edit panel covers common fields per save slot, and a searchable tree exposes every key in the save.

Edits are type- and range-checked, and nothing is ever added, removed or resized. The editor only opens a file if re-encoding it reproduces the original byte for byte. Before each download it reads the new file back and confirms that only your changes differ. Everything runs locally in the browser.
